=== ConnectionString

`struct`

*Implements traits:*

* `Clone`
* `Debug`
* `Eq`
* `FromStr`
* `PartialEq`
* `StructuralPartialEq`

A parsed TypeDB connection string, bundling everything needed to open a driver into a single value: ``typedb://&lt;username&gt;:&lt;password&gt;@&lt;addresses&gt;[/&lt;database&gt;][?&lt;params&gt;]``.

Addresses are comma-separated, and each one must carry an explicit ``http://`` or ``https://`` scheme; all addresses must agree on it, since one TLS configuration covers the whole connection. Each address may instead be a ``public;private`` pair, which produces <<#_enum_Addresses_variant_Translated,`Addresses::Translated`>>; pairs cannot be mixed with plain addresses.

An address without a port is assumed to be on ``DEFAULT_PORT``; an explicit port is kept as written. The database path segment and any query parameters are accepted and discarded: they are meaningful to connection-string producers such as TypeDB Studio, but not to the driver.

[#_struct_ConnectionString_fallback_addresses_]
==== fallback_addresses

[source,rust]
----
pub fn fallback_addresses(&self) -> Option<Addresses>
----

The addresses with every occurrence of the HTTP endpoint’s default port replaced by ``DEFAULT_PORT``, or ``None`` if no address carries it. A connection string produced for the HTTP endpoint, as by TypeDB Studio, names the same server as the gRPC endpoint, so a driver whose connection to the written port is answered with HTTP rather than gRPC retries here.
