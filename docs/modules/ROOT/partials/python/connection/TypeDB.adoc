==== method ``driver_from_connection_string``

[source,python]
----
static driver_from_connection_string(connection_string: str, driver_options: DriverOptions | None = None) -> Driver
----

Creates a connection to TypeDB from a connection string of the form ``typedb://&lt;username&gt;:&lt;password&gt;@&lt;addresses&gt;``.

Whether the connection uses TLS is determined by the addresses’ ``http://`` or ``https://`` scheme. If driver options are given, their TLS configuration must agree with that scheme; otherwise, TLS is configured from the scheme alone, using the system’s native trust roots.

The addresses are connected to as written, with port 1729 assumed where none is given. If an address carries the HTTP endpoint’s default port 8000 and answers with HTTP rather than gRPC, the driver retries on port 1729 and logs a warning, so a connection string copied from TypeDB Studio works unchanged.
