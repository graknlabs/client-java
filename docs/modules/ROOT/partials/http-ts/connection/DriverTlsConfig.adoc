=== DriverTlsConfig

`class`

TLS settings for ``https`` addresses. Without them, the driver trusts the certificate authorities that the runtime trusts by default.

[caption=""]
.Fields
// tag::properties[]
[cols=",,"]
[options="header"]
|===
|Name |Type |Description
a| `rootCAPath` a| `string` a| The path to the PEM file with the certificate of the CA that signed the servers' certificates. When set, the driver trusts only this CA. The file is read on the first https request, and requests fail with HDR3 if it cannot be used. Supported in Node.js only: browsers trust the certificates of their own trust store.
|===
// end::properties[]
